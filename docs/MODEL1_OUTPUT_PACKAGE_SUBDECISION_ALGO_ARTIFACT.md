# Model 1 Output Package Subdecision - Algo File As Separate Artifact

Last updated: April 2, 2026

## Decision

The monthly algo file should be represented as a separate artifact in the Model 1 monthly output package.

It should not be buried only as:

- background context inside the VIR Change Brief
- a subsection inside the Challenge Brief
- an implicit sizing signal hidden in narrative output

## Why

The algo file is part of the real monthly decision workflow.
It reportedly ingests VIR data and suggests sizing considerations across ACIDs for both equity and fixed income.

That makes it distinct from:

- descriptive VIR change analysis
- portfolio alignment review
- challenge and debate framing

It deserves its own surface because it answers a different question:

- given the current opportunity set, what sizing-aware implementation considerations are being suggested?

## Implication For Model 1

The minimum monthly output package may need to include a fourth artifact such as:

- `Opportunity Sizing Snapshot`
- `Sizing Considerations Brief`
- `ACID Sizing Summary`

The exact naming and placement remain open until the algo file is reviewed.

## What Remains Open

Even with this subdecision locked, the broader Model 1 output-package decision is still open pending review of the actual algo file.

We still need to determine:

- whether the monthly package should contain three artifacts plus the sizing artifact, or whether another artifact should collapse into it
- how prescriptive the sizing artifact should sound
- whether the agent should summarize the algo file, critique it, or do both
- what the right PM-facing format is for this artifact
